# Portfólio de Sophia Alberton

Bem-vindo ao repositório do meu portfólio pessoal. Este projeto foi criado para apresentar minhas habilidades, projetos e um pouco sobre minha jornada como desenvolvedora Fullstack.

## ✨ Visão Geral

Este site é uma vitrine do meu trabalho, desenvolvido com foco em um design limpo, moderno e totalmente responsivo. Aqui você encontrará:

* **Sobre Mim:** Uma breve introdução sobre minha paixão por tecnologia e meus objetivos profissionais.
* **Habilidades:** As tecnologias e ferramentas com as quais tenho experiência.
* **Projetos:** Uma seleção de projetos que desenvolvi, com links para o GitHub.
* **Contato:** Meus links profissionais e um formulário para entrar em contato.

## 🚀 Tecnologias Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Design:** Layout responsivo (Mobile First), design moderno e interativo.
* **Ferramentas:** VS Code, Git & GitHub.
